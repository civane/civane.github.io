# civane.github.io

Personal academic website for Zhangxizi QIU — AI Researcher & Engineer.

Built with pure HTML & CSS, hosted on GitHub Pages at **https://civane.github.io**

## Structure

```
civane.github.io/
├── index.html        # Main website
├── assets/
│   └── profile.jpg   # Profile photo
└── README.md
```

## Deployment

Push to the `main` branch — GitHub Pages serves `index.html` automatically.

Go to **Settings → Pages → Source → Deploy from branch → main / (root)**.
